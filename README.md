# Lab2Shot

**中文** | [English](README.en.md)

<p align="center"><img src="docs/images/welcome.png" alt="Lab2Shot" width="900"></p>

Lab2Shot 将机器学习研究成果引入计算机图形制作流程。项目把已发表的研究代码（摄影机解算、抠像、人体与面部捕捉、光照估计等）封装为节点，供影视与游戏美术人员直接使用。全部结果以标准格式交付：三维数据为 USD（Y 轴向上，单位厘米），图像为 EXR / PNG / JPG，颜色由 OCIO 管理，可直接导入 Houdini、Maya 与 Nuke。

做这个项目的初衷很简单：让更多一线制作人员用上最新的科研成果。这里的每一种方法都是原作者的研究成果，Lab2Shot 只负责把它接进制作流程，不改动原项目的代码。

## 功能

Lab2Shot 以接入层的形式接入第三方研究项目，按制作任务组织成节点。镜头与场景方面，可以从实拍画面解算摄影机与镜头畸变，重建场景的三维几何，估计深度与法线；画面处理方面，可以抠像、生成遮罩、跟踪、计算光流与对位；人物方面，可以从视频中捕捉人体动作和面部表情，并编辑动作；此外还能估计场景的光照与材质。所有结果都按统一格式交付。

各接入层的节点、输入输出、显存需求与许可证说明见 `adapters/<项目名>/docs.md`。

## 安装

需要 Linux 或 WSL2、NVIDIA 显卡及驱动、Node.js 20.19+ 或 22.12+（Python 由 [uv](https://docs.astral.sh/uv/) 自动安装）。在仓库根目录执行：

```bash
./setup.sh
```

按菜单依次执行「首次安装向导」「扩展包编译与下载设置向导」「扩展包安装向导」即可，每一步执行前都会说明其作用。安装、服务、设置与数据库的操作都在这个菜单里。

少数模型须自行下载或先申请访问，清单见 [docs/manual-downloads.md](docs/manual-downloads.md)。

## 升级

先备份工作目录，在原版本中停止服务（可选择等待当前任务完成），再手动拉取代码，最后运行新版升级程序：

```bash
./setup.sh stop
git pull --ff-only
./setup.sh update
```

拉取前请提交或暂存本地代码改动，处理好 Git 报告的冲突。升级程序备份设置、本地受管文件及数据库，随后同步依赖、构建网页、检查、迁移数据库并启动服务。它不执行 Git 拉取。环境同步之后失败时，会恢复上次部署的代码、数据库与环境并启动原版本；首次升级从刚执行的手动拉取记录取得回退版本。升级成功后，按提示重新安装需要重装的扩展包。

## 使用

在浏览器中打开服务地址并登录，从模板新建节点图，指定素材、调整参数后提交任务；任务排队由显卡计算，完成后下载结果。

## 架构

- 核心（`lab2shot/`）不导入任何第三方研究项目，只负责界面、调度、节点图与统一的输入输出。
- 每个研究项目对应 `adapters/<项目名>/` 一个目录，在自己的独立环境中由 worker 进程计算，与核心只交换文件与消息。
- 第三方仓库按锁定版本原样获取到 `third_party/`，不作任何修改。
