# Lab2Shot Maya 插件：安装说明

**中文** | [English](INSTALL.en.md)

支持 Maya 2024、2025、2026（Windows）。插件只用 Maya 自带的 Python 和 Qt，不往 Maya 里装任何东西，也不改 Maya 安装目录。

## 安装

1. 解压这个压缩包，里面有 `lab2shot.mod` 文件和 `lab2shot` 文件夹。
2. 把这两样一起复制到 `文档\maya\modules\`（即 `C:\Users\<你的用户名>\Documents\maya\modules\`；没有 `modules` 文件夹就新建一个）。
   复制完是这样：
   ```
   Documents\maya\modules\lab2shot.mod
   Documents\maya\modules\lab2shot\scripts\...
   ```
3. 重启 Maya。菜单栏出现「Lab2Shot」就装好了。第一次启动时 Maya 可能问是否允许运行 `userSetup.py`，选允许。

升级：用新的压缩包覆盖这两样，重启 Maya。卸载：删掉这两样，重启 Maya。

## 第一次使用

1. 菜单「Lab2Shot → 登录…」，填服务器地址（管理员告诉你的网址，例如 `https://lab2shot.example.com`）、账号、密码。
   还没有账号？请到网页端注册。
2. 「Lab2Shot → 打开面板」。面板首页是全部工具：上面是搜索框；在场景里选中东西（摄影机、带图像平面的摄影机、角色、骨架）后，
   「适合当前选中」一行列出能用它的工具；下面按分类分标签（「最近用过」在最后）。每张卡片写着工具名、一句说明和「需要：图像、摄影机」。
3. 点一张卡片：场景里多一个 Lab2Shot 节点（`lab2shot1`），面板转到这个工具。从「适合当前选中」点的卡片，会把选中的东西直接绑到能用的输入上。
   当前节点已经有工具时，点卡片会新建一个节点：每个任务一个节点，以前的结果版本不受影响。
4. 工具页从上到下三步：
   - ① 输入：每个输入一张卡片，点「用选中的」用场景里选中的东西，或者「选文件」/「选序列」（序列可以在文件夹里全选所有帧，也可以只选其中一帧）。
     序列会显示首帧、尾帧和帧数。
   - ② 设置：常用的直接显示，「高级」默认折叠。标「来自场景」的是从场景读到的（帧范围、帧速率、焦距……），可以改。
   - ③ 计算：点「计算」。计算在服务器上进行，Maya 照常可用；进度在按钮下面，按钮变成「取消」，随时可以取消。
5. 算完自动导入：结果是新的对象，放在大纲的 `Lab2Shot` 组下（`lab2shot1_v001`），命名空间 `l2s_lab2shot1_v001`。
   每次计算都给新的一份；插件不改、不删场景里原有的任何东西。导入是一个撤销步，按一次 Ctrl+Z 整次撤掉。
   结果里有摄影机时，新摄影机上挂一个新的图像平面：绑定了画面就用这个画面；没绑定画面就用绑定的摄影机自己图像平面上的画面；
   两样都没有就不挂，面板上会说一句。
6. 工具页最下面是结果版本（横排）。点一个已导入的版本，选中它的对象；没导入的版本（结果太大时会先问你），点它再导入，不用重新下载。
   右键可以打开它的文件夹。结果文件在 Maya 工程的 `data\lab2shot\<节点名>\v001\` 下。
7. 在场景里选中一个 Lab2Shot 节点，面板自动转到它；首页的「本场景的任务」也列着场景里每个节点。顶部「← 全部工具」回到首页。
   关掉场景再打开，在工具页右上角「⋯ → 取回结果」可以再取上次的结果（服务器保留几天）。
8. 语言：面板右上角「⋯ → 语言」，可以跟随 Maya、中文或 English，切换后面板和菜单马上换过来。

## 出了问题

- 插件自己的日志在 `C:\Users\<你的用户名>\lab2shot\maya.log`（面板「⋯ → 日志文件夹」或菜单「日志文件夹」打开它）。插件出错只写日志、在面板上说一句，不会影响 Maya。
- 菜单没出现：看上面的日志；确认 `lab2shot.mod` 和 `lab2shot` 文件夹在同一个 `modules` 文件夹里。
- 连不上服务器：检查地址；服务器用自己签发的 HTTPS 证书时，压缩包里已经带了它（`lab2shot\scripts\lab2shot_ca.pem`），插件会额外信任它。
