# MeshRet 动作重定向

官方仓库：https://github.com/abcyzj/MeshRet

## 怎么用（三段）

1. **重定向预处理**：「动作」接源动画（骨架动画或蒙皮角色），「目标」接要套上动作的角色。在视图里定两副骨架的部位对应、两侧的参考姿态（初始姿态对齐）和不送进解算器的骨骼；三件都有「自动」，默认就按自动算。「忽略规则」选「MeshRet（身体与手指，模型只驱动身体）」。
2. **本节点（解算）**：「源」「目标」接预处理的两个输出。送进来的骨骼不合本节点的规则时报错，指回预处理去改——解算器自己不丢骨骼。结果是模型原生的输出，写回目标自己的层级；没送进模型的骨骼保持参考姿态的局部、跟着父骨骼走。节点信息里列出实际送进模型的关节数和适配层补出的标记点。
3. **重定向后处理**：位移轨迹（跟随源动作 / 保留模型）和高度偏移；再接线性蒙皮变形看网格、接自动落地贴地。

帧率必须与源动画解释的帧率一致。

模型需要两侧真实蒙皮网格；裸骨架需要先挂到匹配的角色上。输入投影到官方 65 关节的扩展 Mixamo 骨架（含手指：掌心的表面传感器按手腕到中指根计算），骨架缺的手指节、头顶和脚尖末端点由适配层补出标记（沿骨骼延长，或按手掌、头、脚的表面估计）。已发布模型只驱动其中 25 个身体关节，手指保持目标的参考姿态。
