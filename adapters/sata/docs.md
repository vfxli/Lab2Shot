# SATA 动作重定向

官方仓库：https://github.com/zzysteve/SATA

## 怎么用（三段）

1. **重定向预处理**：「动作」接源动画（骨架动画或蒙皮角色），「目标」接要套上动作的角色。在视图里定两副骨架的部位对应、两侧的参考姿态（初始姿态对齐）和不送进解算器的骨骼；三件都有「自动」，默认就按自动算。「忽略规则」选「SATA（官方人体范围）」（躯干与四肢，官方人体样例的范围），或「SATA（加手指，实验）」——更多关节不代表效果更好。
2. **本节点（解算）**：「源」「目标」接预处理的两个输出。送进来的骨骼不合本节点的规则时报错，指回预处理去改——解算器自己不丢骨骼。结果是模型原生的输出，写回目标自己的层级；没送进模型的骨骼保持参考姿态的局部、跟着父骨骼走。节点信息里列出实际送进模型的关节数和适配层补出的标记点。
3. **重定向后处理**：位移轨迹（跟随源动作 / 保留模型）和高度偏移；再接线性蒙皮变形看网格、接自动落地贴地。

帧率必须与源动画解释的帧率一致。

模型使用官方拓扑图和已发布权重，输入层级必须单根并按父节点在前排列。关节的语义文字按部位取官方名称表里的描述（T5-base 编码）；脚趾的语义（脚趾根部 / 大脚趾）可在「关节语义」里手调。
